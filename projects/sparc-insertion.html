Sensorless Precision Insertion for a SCARA Manipulator

Analog Devices India – Anveshan · 2026 – present

A manipulation project exploring whether contact, jamming and insertion state can be inferred from motor-driver electrical signatures instead of adding dedicated force/torque sensors.

ProblemBuildArchitectureValidationMediaStack

Problem

Precision insertion normally benefits from force/torque sensing, but those sensors add cost and mechanical complexity. The objective is to recognize contact and failure states from signals already available in the actuator electronics, then use that information to make insertion safer and more reliable.

Simulation and estimation workflow

Manipulation benchmark

Built a MuJoCo simulation framework with scenarios including nominal insertion, partial insertion, jamming, yaw misalignment, uncertain pose, obstacle interaction, high friction and edge contact.

Sensorless signal path

The intended estimator uses motor-driver current / electrical behaviour to infer actuator load and contact transitions, avoiding a dedicated force sensor at the end effector.

Failure-aware evaluation

Insertion is evaluated not only as success/failure but through contact mode, force-limit events, alignment and timing, making it possible to compare control and estimation strategies across controlled failure cases.

Sim-to-real target

The estimator and control interface are being prepared for deployment on Analog Devices MAX32690 control hardware with TMC2209 motor drivers.

Simulation results

  • Core model, environment and planning tests passed across the simulation framework.
  • Nominal encoder/ideal insertion completed successfully in approximately 5.6 s in one validated setup.
  • A driver + stepper configuration correctly surfaced a force-limit failure at roughly 79 N peak, demonstrating that the benchmark can distinguish successful insertion from unsafe contact.
  • Current work is focused on extracting robust features from motor-driver signals and validating the same failure modes on hardware.
