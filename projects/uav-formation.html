Selected project

Multi-UAV Formation Control on Crazyflie

Control Engineering Lab + Distributed Intelligence and Robotics Lab, IIT Madras · Aug 2026 – present

Extending a published multi-UAV beamforming / formation-control framework toward physically realizable quadrotor motion, then validating the resulting trajectories on Crazyflie nano-UAVs with motion-capture feedback.

Problem

A formation optimizer can generate geometrically ideal drone trajectories that are impossible for a real quadrotor to follow. Translational acceleration requires roll and pitch, thrust is bounded, and aggressive trajectories can create tracking error that directly changes the array geometry and beam-pointing direction.

Research direction

6-DOF vehicle model

Reformulated the trajectory problem around nonlinear quadrotor dynamics rather than treating each drone as an unconstrained point mass.

Physical limits

Explicitly account for roll, pitch, thrust, velocity and actuator limits so the optimized motion remains dynamically feasible.

Joint objective

Study the trade-off between trajectory-tracking error and beam-pointing / formation error instead of optimizing only geometric formation quality.

Hardware loop

Crazyflie vehicles provide the physical platform, while OptiTrack supplies closed-loop position estimates for controlled validation against the reference formulation.
