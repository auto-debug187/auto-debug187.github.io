Project skincAIr

Sahaay, IIT Madras

A computer-vision prototype that classifies skin-condition imagery and converts model output into a structured, readable report. It was developed as an engineering prototype rather than a clinical diagnostic system.

DomainComputer vision
ModelCNN
FrameworkTensorFlow
Prototype accuracy92%
ProblemBuildArchitectureValidationMediaStack

Problem

Image classifiers often stop at a class label, while practical workflows need consistent context and a readable record of the model output. This project combined visual classification with a structured reporting layer.

Pipeline

  • Built and trained a CNN-based skin-condition classifier in Python / TensorFlow.
  • Reached 92% accuracy on the project's evaluation split.
  • Added an LLM-based structured reporting layer to turn model predictions into a consistent report format.
Scope: research / prototype software only; not intended to provide medical diagnosis.
