# Portfolio media directory

All project images, diagrams and videos referenced by the site live in this single directory.

The HTML files use fixed filenames so you can upload/replace media without editing layout code. Missing images automatically fall back to `placeholder.svg`; missing MP4s keep the placeholder poster.
